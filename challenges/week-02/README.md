# Week 02 - Dynamic Programming and Memory

Welcome to **Week 02** of the LeetCode Lab.

This week builds upon the foundations established in Week 01 by introducing problems that require remembering previous computations and making optimal decisions.

These challenges closely align with concepts from Artificial Intelligence, particularly memory mechanisms used in Recurrent Neural Networks (RNNs) and Long Short-Term Memory (LSTM) networks.

Throughout this week, you will practice:

- Dynamic Programming
- State-based computation
- Optimization
- Data Structure Design
- Memory management
- Efficient algorithms

# 📂 Challenge Structure

Every challenge follows the same structure.

```
lc-xxxx-problem-name/
│
├── README.md
├── solution.py
├── test_solution.py
├── hints.md
└── editorial.md
```

Each file has a specific purpose.

| File | Description |
|------|-------------|
| README.md | Problem description and instructions |
| solution.py | Write your solution here |
| test_solution.py | Automated PyTest test cases |
| hints.md | Progressive hints |
| editorial.md | Detailed explanation after solving |

# 🚀 How to Complete a Challenge

For every challenge:

1. Read the problem statement.
2. Understand the examples.
3. Open `solution.py`.
4. Implement your solution.
5. Run the tests.
6. Fix any failing test cases.
7. Commit your work.
8. Push your branch.
9. Create a Pull Request.
