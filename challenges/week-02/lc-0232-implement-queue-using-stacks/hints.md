# 💡 Hints - LC-0232: Implement Queue using Stacks

Reveal one hint at a time.

---

# Hint 1

A queue follows **FIFO**.

A stack follows **LIFO**.

How can two stacks together simulate FIFO behavior?

---

# Hint 2

Use one stack for inserting new elements.

---

# Hint 3

Use another stack for removing elements.

---

# Hint 4

Only transfer elements from the input stack to the output stack when necessary.

---

# Hint 5

Once elements are transferred,

the oldest inserted element appears on top of the output stack.

---

# Final Hint

Maintain two stacks:

- Input Stack
- Output Stack

Transfer elements only when the output stack is empty.

Good luck! 🚀
