# 💡 Hints - LC-0605: Can Place Flowers

Reveal one hint at a time.

---

# Hint 1

You only need to inspect the current plot and its immediate neighbors.

---

# Hint 2

A flower can only be planted if:

- Current plot is empty.
- Left plot is empty (or doesn't exist).
- Right plot is empty (or doesn't exist).

---

# Hint 3

Remember to handle the first and last positions carefully.

They do not have two neighbors.

---

# Hint 4

Whenever you successfully plant a flower,

update the flowerbed before continuing.

---

# Hint 5

Count how many flowers have been planted.

Stop early if you've already planted `n` flowers.

---

# Final Hint

Traverse the flowerbed once while checking neighboring plots before making each decision.

Good luck! 🚀
