These challenges also reinforce concepts taught during the Artificial Intelligence and Machine Learning lectures, particularly how information flows through sequential models such as Recurrent Neural Networks (RNNs).

# 📂 Challenge Structure

Every challenge (except the example solution) follows the same structure.

```
lc-xxxx-problem-name/
│
├── README.md
├── solution.py
├── test_solution.py
├── hints.md
└── editorial.md
```

Each file has a specific purpose.

| File | Description |
|------|-------------|
| README.md | Problem description and instructions |
| solution.py | Write your solution here |
| test_solution.py | Automated PyTest test cases |
| hints.md | Progressive hints |
| editorial.md | Detailed explanation after solving |

---

# 🚀 How to Complete a Challenge

For every challenge:

1. Read the problem statement.
2. Understand the examples.
3. Open `solution.py`.
4. Implement your solution.
5. Run the tests.
6. Fix any failing test cases.
7. Commit your work.
8. Push your branch.
9. Create a Pull Request.
