# 📖 Overview

This repository contains the instructor's reference implementation for **LeetCode 125 – Valid Palindrome**.

The goal of this example is **not simply to provide the answer**, but to demonstrate how an engineer approaches a coding problem from start to finish.

Students are encouraged to study the overall problem-solving process rather than memorizing the implementation.

---

# 🎯 Learning Objectives

After studying this example, you should be able to:

- Read and understand a coding problem.
- Break the problem into smaller steps.
- Select an appropriate algorithm.
- Write clean and readable Python code.
- Analyze time and space complexity.
- Validate your solution using automated tests.
- Follow a professional Git and GitHub workflow.

---

# 📚 Why This Example?

Many beginners jump directly to writing code.

Professional software engineers usually follow a structured approach:

1. Understand the problem.
2. Identify inputs and outputs.
3. Consider possible edge cases.
4. Design an efficient solution.
5. Implement the solution.
6. Test the implementation.
7. Review and improve the code.

This example demonstrates that complete workflow.

# 🚀 How to Study This Example

Follow these steps instead of immediately reading the solution.

### Step 1

Read the original problem statement on LeetCode.

Try solving it yourself.

---

### Step 2

Compare your solution with the instructor's implementation.

Ask yourself:

- Did I choose the same approach?
- Is my solution easier to read?
- Is my solution efficient?
- Can I simplify my code?

---

### Step 3

Read the editorial.

Understand:

- Why this algorithm was chosen.
- Alternative approaches.
- Time Complexity.
- Space Complexity.

---

### Step 4

Run the automated tests.

```bash
pytest
```

Observe how different test cases validate the solution.

---

### Step 5

Experiment.

Try modifying the solution.

Can you improve it?

Can you write the same algorithm differently?
