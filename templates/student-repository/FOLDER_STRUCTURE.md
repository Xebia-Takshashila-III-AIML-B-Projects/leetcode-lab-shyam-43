# Student Repository Structure

Every student repository must follow the same structure.

```text
leetcode-lab-<register-number>/
│
├── week-01/
│   ├── lc-0001-two-sum.py
│   ├── lc-0125-valid-palindrome.py
│   └── lc-0242-valid-anagram.py
│
├── week-02/
│
├── week-03/
│
├── week-04/
│
├── week-05/
│
├── notes/
│   ├── week-01.md
│   ├── week-02.md
│   └── ...
│
├── certificates/
│
├── README.md
└── .gitignore
```

# Repository Rules

- One solution file per challenge.
- Do not rename challenge files.
- Do not modify folder names.
- Keep weekly folders organized.
- Update README regularly.
