# 📚 LeetCode Lab Documentation

Welcome to the official documentation for **LeetCode Lab**.

This documentation has been written specifically for students who are new to software development, Git, GitHub, and collaborative programming.

The documents in this folder will guide you through every step of the semester—from setting up your computer to solving coding challenges using an industry-standard workflow.

# 🎯 Purpose of LeetCode Lab

The goal of LeetCode Lab is not only to solve programming problems but also to introduce students to professional software engineering practices.

Throughout the semester, you will learn to:

- Solve coding challenges
- Think algorithmically
- Write clean Python code
- Use Git professionally
- Collaborate using GitHub
- Create Pull Requests
- Follow coding standards
- Read technical documentation

# 🚀 Learning Path

To get the best learning experience, follow this sequence for every new challenge.

```text
Read Challenge
      │
      ▼
Understand the Problem
      │
      ▼
Create a Feature Branch
      │
      ▼
Implement Your Solution
      │
      ▼
Run Unit Tests
      │
      ▼
Commit Your Changes
      │
      ▼
Push Your Branch
      │
      ▼
Create a Pull Request
      │
      ▼
Repeat
```

# 📌 Before You Begin

Ensure you have:

- A GitHub account
- Access to the GitHub Organization
- Python installed
- Git installed
- Visual Studio Code installed
- Your personal repository created

If not, begin with **01-getting-started.md**.
